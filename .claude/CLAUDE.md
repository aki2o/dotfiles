# グローバル設定

## Bash 実行

- **`cd` を使わない。** ファイル・ディレクトリは常に絶対パスで指定する。
  - ✅ `ls /path/to/dir` / `grep -n foo /path/to/file.ts`
  - ❌ `cd /path/to/dir && ls`
- **1回のツール呼び出しにつき1コマンド。** `&&` や `;` で繋げない。
  独立した調査が必要なら、複数のツール呼び出しに分けて並列に実行する。
- パイプ（`grep ... | head`）は、各コマンドが allow ルールに載っていれば使ってよい。
- **`git -C <path>` を主リポジトリに対して使わない。** Bash ツールの作業ディレクトリは既にプロジェクトルートなので `git show` / `git log` のように素で実行する。
  allow ルールは前方一致のため `Bash(git show:*)` は `git -C ... show` にマッチせず、確認プロンプトが出る。

理由: `~/.claude/settings.json` に `Bash(cd:*)` 等の allow ルールがあっても、`cd` を含む複合コマンドは各部分の実行ディレクトリが確定できないため権限確認プロンプトが出て毎回作業が止まる。
